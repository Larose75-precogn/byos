# byos — Own Storage

Le stockage propriétaire de l'organisation (BYOS) : registre des organisations et des briques,
cascade de règles, secrets chiffrés par organisation, journal technique, et l'accès Google Drive.
Le `journal.ledger` comptable vit dans le Drive de l'organisation ; ce composant en orchestre
la lecture/écriture et la structure de briques (Objects / Flows / Rules / Time).
